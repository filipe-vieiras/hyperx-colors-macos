# Privacy

The application stores color, brightness, effect, speed and startup preferences locally with macOS UserDefaults. It does not record microphone audio, create an account, collect analytics, or make network requests. It sends USB lighting commands to the connected microphone.

Enabling launch at login registers the app with macOS ServiceManagement. macOS may require user approval. The user can disable the option in the app or manage it in System Settings.

GitHub downloads, issues and contributions are subject to GitHub's own policies. Do not post personal information or device serial numbers in public issues.
